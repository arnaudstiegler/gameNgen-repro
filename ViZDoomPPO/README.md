# ViZDoom PPO Agent Training

## Purpose

This directory contains the necessary scripts and configurations for training a Proximal Policy Optimization (PPO) agent using the [ViZDoom](https://vizdoom.cs.put.edu.pl/) environment. The trained agent learns to play a basic deathmatch scenario, and its gameplay data is then used as input for the gameNgen project, which aims to generate game content.

## Setup

1.  **Environment**: It's recommended to use a Python virtual environment (e.g., `venv` or `conda`).
    ```bash
    python -m venv .venv
    source .venv/bin/activate 
    ```
2.  **Dependencies**: All required Python packages are listed in the main `requirements.txt` file at the root of this repository. Ensure you have installed them before proceeding:
    ```bash
    pip install -r ../requirements.txt 
    ```
    *(Note: The `../` assumes you are running this command from within the `ViZDoomPPO` directory).*

## Core Scripts

### 1. Training the Agent

*   **Script**: `train_ppo_parallel.py`
*   **Purpose**: This script trains the PPO agent on the ViZDoom `deathmatch_simple` scenario. It utilizes Stable Baselines3 for the PPO implementation and parallel environments for faster training.
*   **Example Command**:
    ```bash
    python train_ppo_parallel.py
    ```
*   **Output**: Trained models are saved incrementally, with the best performing model typically found at `ViZDoomPPO/logs/models/deathmatch_simple/best_model.zip`. TensorBoard logs are also generated under `ViZDoomPPO/logs/tensorboard/`.

### 2. Generating Datasets and GIFs with a Trained Agent

*   **Script**: `load_model_generate_dataset.py`
*   **Purpose**: This script loads a pre-trained agent (like the one generated by `train_ppo_parallel.py`) to:
    *   Generate datasets of agent gameplay (sequences of frames, actions, etc.) in Parquet format. These datasets can then be uploaded to Hugging Face Hub.
    *   Create GIF files of agent gameplay for qualitative analysis (QA) of the agent's behavior.
*   **Example Commands**:
    *   To generate a dataset and upload it to Hugging Face Hub:
        ```bash
        python load_model_generate_dataset.py --episodes {number_of_episodes} --output parquet --upload --hf_repo {your_hf_username/repository_name}
        ```
        (Replace `{number_of_episodes}` and `{your_hf_username/repository_name}` accordingly)
    *   To generate a GIF for QA:
        ```bash
        python load_model_generate_dataset.py --episodes 1 --output gif
        ```
        (This will typically save the GIF in the `ViZDoomPPO` directory or a subdirectory specified by the script, e.g., `ViZDoomPPO/gifs/`)

## Artifacts

*   **Trained Agent**: The primary output of the training process.
    *   Location: `ViZDoomPPO/logs/models/deathmatch_simple/best_model.zip`
*   **Generated Datasets**: Gameplay data recorded from the trained agent.
    *   Format: Typically Parquet files.
    *   Generated by: `load_model_generate_dataset.py`. The exact output path might vary based on script arguments but datasets are meant for upload or further local processing.
*   **GIFs**: Visual recordings of agent gameplay.
    *   Generated by: `load_model_generate_dataset.py --output gif`.
*   **Logs**: Training progress and metrics.
    *   Location: `ViZDoomPPO/logs/tensorboard/`
